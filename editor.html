Datei wählen oder Text einfügen — der Editor liest alle Formate, die er auch schreibt. Das Format wird am Inhalt erkannt, die Dateiendung ist egal.

TypeScript, JavaScript, JSON, Python und C-Header bringen die Farb-Nummern mit und kommen unverändert zurück. SVG, CSS und Text-Raster kennen keine Nummern — dort bleibt das Bild gleich, die Farben werden neu durchnummeriert.

Hilfe

Pixel-Editor mit Foto-Vorlage. Du malst frei — oder paust ein Foto als Schablone ab und lässt es automatisch zu einem sauberen Sprite verarbeiten.

Farbpaletten

Eine Palette bildet Index → Farbe ab. 0 ist immer transparent, 1–9 sind frei belegbar.
Konvention (kein Zwang): 1–4 eine Tonleiter hell → dunkel, 5 die Kontur, 6–9 Akzente.
Jeder Sprite merkt sich seine eigene Palette. Farbe ändern färbt alle Pixel mit diesem Index sofort um.
Eingebaute Paletten sind schreibgeschützt — Kopie bearbeiten macht eine änderbare eigene daraus.

Werkzeuge

Stift — einzelne Pixel.
Pinsel — Fläche; Stärke = Dichte, Größe = Kantenlänge.
Spray — zufällige Pixel; Stärke = Menge pro Ereignis.
Füllen — zusammenhängende gleiche Fläche.
Radierer — setzt auf transparent.
Zauberstab — löscht zusammenhängende ähnliche Fläche; Toleranz steuert, wie viel Abweichung mitgeht.
Linie · Rechteck · Ellipse — aufziehen, die Vorschau zeigt das Ergebnis, Loslassen zeichnet. Gefüllt schaltet zwischen Kontur und Fläche.
Auswahl · Lasso · Farbwahl — drei Wege zur selben Sache: ein Bereich, den man als Ganzes bewegt.

Symmetrie

Die beiden Knöpfe ↔ und ↕ in der Werkzeugleiste spiegeln jeden Strich an der Mittelachse — beide zusammen ergeben vier Spiegelungen.
Gilt für Stift, Pinsel, Spray, Füllen und die Formen. Die Achsen werden als gestrichelte Linien eingeblendet.

Auswahl: ausschneiden und verschieben

Auswahl (A) zieht ein Rechteck auf.
Lasso (L) umfährt eine freie Form; beim Loslassen wird sie geschlossen und alles darin gehört dazu — auch bei krakeliger Linie.
Farbwahl (K) nimmt die zusammenhängende ähnliche Fläche unter dem Klick; die Toleranz bestimmt, wie viel mitgeht.
In die Auswahl fassen und ziehen → der Bereich wird ausgeschnitten und schwebt. Er bleibt in der Luft, bis du ihn absetzt — solange lässt er sich beliebig oft verschieben, drehen und spiegeln, ohne dass darunter etwas kaputtgeht.
Abgesetzt wird beim Abwählen (Esc), bei einer neuen Auswahl, beim Werkzeug- oder Sprite-Wechsel — oder automatisch beim Schließen des Tabs.
Alt+Ziehen lässt das Original stehen — man verschiebt eine Kopie.
Feinarbeit mit den Pfeiltasten: ein Pixel pro Druck. Füllen färbt die ganze Auswahl in der aktuellen Farbe.
Beim Absetzen überschreiben nur gefüllte Pixel; transparente Stellen lassen den Untergrund stehen.
Was über den Rand hinausgeschoben wird, geht verloren — Strg+Z holt alles zurück.
Ein Klick neben die Auswahl (oder Esc) hebt sie auf.

Bild

Spiegeln und Drehen wirken auf die Auswahl, wenn es eine gibt — sonst auf den ganzen Sprite. Das Abzeichen im Panel sagt, worauf gerade.
Zuschneiden schneidet den leeren Rand weg, Zentrieren rückt den Inhalt in die Mitte.
Größe ändert die Fläche, ohne zu skalieren; der Anker bestimmt, wohin der alte Inhalt rutscht.
×2 / ÷2 skaliert hart (Nearest Neighbor) — Pixel bleiben Pixel, beim Halbieren fällt jedes zweite weg.
Frei drehen nimmt jeden Winkel. Der Regler zeigt eine Vorschau; Übernehmen (Enter) schreibt sie fest, Verwerfen (Esc) geht zurück auf 0°.
Jede Vorschau wird vom Original gerechnet, nicht vom zuletzt gedrehten Bild — dreimal am Regler ziehen verwäscht die Form also nicht.
Bei einer Auswahl wächst der Rahmen mit, damit nichts abgeschnitten wird. Beim ganzen Sprite bleibt die Fläche gleich, Ecken außerhalb fallen weg.

Ebene — mit zwei Sprites arbeiten

Unter der Sprite-Liste lässt sich ein zweiter Sprite als Ebene einblenden: halbdurchsichtig, oben links ausgerichtet, mit eigener Palette.
Bearbeitet wird immer nur der aktive Sprite — die Ebene ist reine Vorlage. 👁 blendet sie aus, der Regler stellt die Deckkraft, dahinter/davor legt sie unter oder über das Bild (zum Abpausen von Konturen).
Tauschen vertauscht die Rollen: die Ebene wird bearbeitet, der bisherige Sprite wird zur Ebene.
Teile übertragen: im einen Sprite auswählen und Strg+C, zum anderen wechseln, Strg+V. Das Eingefügte schwebt und lässt sich erst hinschieben, bevor es liegt.

Schablone

Bild laden, mit Shift+Linksklick ziehen verschieben, Deckkraft und Größe per Regler.
Shift halten → Schablone voll in den Vordergrund.
Shift+Rechtsklick → Schablonen-Pipette (exakte Farbe aus dem Bild).
Bleibt nach einem Reload erhalten.

Foto → Sprite

  1. Foto als Schablone laden und übers Grid legen
  2. Reduzieren auf ~8 Farben übernehmen
  3. Bild → Palette — die Farben werden zur editierbaren Palette
  4. Hintergrund entfernen (oder Zauberstab)
  5. Glätten, dann Outline drüber
  6. Reste von Hand mit Stift und Radierer säubern

Import & Export

Import liest number[][] aus Text oder Datei — TypeScript, JavaScript und JSON. Ein mitgelieferter Palettenblock wird als eigene Palette angelegt und zugewiesen.
Code-Feld erzeugt den Export im gewählten Format. Freie Pipetten-Farben werden als Indizes oberhalb der Palette gesichert — bei TS, JS und JSON ist der Round-Trip verlustfrei.
TypeScript / JavaScript — number[][] plus Palette, mit oder ohne Typen.
JSON — sprachneutral für eigene Pipelines, Engines und Tools.
SVG — fertige Vektorgrafik, skaliert verlustfrei; gleiche Farbe nebeneinander wird zu einem Rechteck zusammengefasst.
CSS — der Sprite als box-shadow auf einem einzigen Element, ganz ohne Bilddatei.
C-Header — uint8-Indizes plus uint32-Palette für Mikrocontroller und LED-Matrizen.
Python — Dict und Liste für Pygame, Pillow oder eigene Skripte.
Text-Raster — ein Zeichen pro Pixel mit Legende; praktisch für Diffs und Doku.
PNG / PDF exportieren transparent; mit Farb-Legende wird die Palette ins Bild gerendert.
Spritesheet packt alle Sprites in gleich große Zellen und legt einen JSON-Atlas mit Namen und Koordinaten daneben — so lesen Engines es direkt ein.
Projekt sichern / Öffnen schreibt alle Sprites und Paletten in eine JSON-Datei.
