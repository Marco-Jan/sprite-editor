01 Der erste Pixel

Mal einfach los.

Hi, ich bin Bitty! Im Raster siehst du mich als Beispiel — mal mich ruhig um. Im Editor helfe ich dir weiter.

Farbe wählen, klicken, ziehen — genau so fühlt sich der Editor an. Nur mit mehr Werkzeugen, Ebenen und einer Timeline für Animationen.

  • Ziehen malt durchgehend, Rechtsklick radiert.
  • Alles bleibt in deinem Browser — kein Konto, nichts wird hochgeladen.
  • Weiter unten wird aus einer Skizze Pixel-Art.

02 Skizze

Aus deiner Skizze wird Pixel-Art.

→

Zeichne auf Papier, mach ein Foto davon und lade es hier — die Striche werden zur Kontur, geschlossene Flächen füllen sich, und die Palette bestimmst du selbst.

  • Dein Bild bleibt in deinem Browser — nichts wird hochgeladen.
  • Im Editor geht das genauso mit der Schablone, samt Feinschliff und Licht.
  • Das Bild merkt sich nur Nummern: Palette tauschen färbt alles um.

03 Für Spiele

Ein Sprite kommt selten allein.

Eine Figur, ihr Hund, ein Vogel, ein ganzes Level: Animationen, Kacheln und eine Vorlage aus einem Foto — alles für dein Spiel an einem Ort.

  • Animation

    Frames, Ebenen und Tags in einer Timeline — mit Onion Skin und eigenem Tempo je Frame.

  • Kacheln

    Eine Kachel anmalen, überall geändert — so entstehen Levels und Muster. Raus direkt nach Godot.

  • Foto als Vorlage

    Foto laden, darüberlegen, auf wenige Farben eindampfen — die Farben aus dem Bild werden zu deiner Palette.

Mehr entdecken

  • Funktionen Werkzeuge, Ebenen, Licht, Hilfslinien — alles, was der Editor kann.
  • Export Bild, GIF, Spritesheet, Godot oder fertiger Code für dein Projekt.
  • Desktop-App spritebit für Windows — größere Flächen, aktualisiert sich selbst.

Das Raster ist noch leer.

Kein Konto, kein Server, keine Kosten. Der Editor öffnet sich und wartet auf deinen ersten Pixel.

Editor öffnen

Einmal geöffnet, läuft alles auch ohne Internet — sogar der PDF-Export. Als Browser-App installiert, startet spritebit wie ein eigenes Programm.
