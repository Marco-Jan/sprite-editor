Pixel-Art-Editor · reines Frontend

Ein Pixel ist eine Zahl.

Sprite Editor ist ein Pixel-Art-Werkzeug, das komplett im Browser läuft. Du malst auf einem Raster aus Paletten-Indizes und nimmst das Ergebnis als TypeScript, JSON, SVG, PNG oder C-Header wieder mit.

Editor öffnen Was drin ist

Läuft im Browser. Keine Anmeldung, keine Cloud, kein Build — deine Pixel bleiben im localStorage auf deinem Rechner.

Werkzeuge

Sechs Panels, ein Raster

Alles sitzt in einklappbaren Panels um die Zeichenfläche. Jede Aktion ist ein einzelner Undo-Schritt, auch wenn sie das ganze Grid austauscht.

  • Zeichnen

    Stift, Pinsel, Spray, Füllen, Radierer und Zauberstab. Linie, Rechteck und Ellipse ziehen mit Live-Vorschau, umschaltbar zwischen Kontur und Fläche.

    Symmetrie an zwei Achsen spiegelt jeden Strich mit.

  • Auswahl

    Rechteck, Lasso für freie Formen, Farbauswahl mit Toleranz. Der gewählte Bereich wird ausgeschnitten und schwebt, bis du ihn absetzt.

    Verschieben, frei drehen, spiegeln, kopieren — der Untergrund bleibt heil.

  • Paletten

    Index-basiert: 0 ist transparent, 1–9 belegst du frei. Neun Farbschemata sind eingebaut, eigene legst du daneben an.

    Eine Farbe ändern färbt alle Pixel mit diesem Index sofort um.

  • Foto-Vorlage

    Bild laden, über das Raster legen und per Median-Cut auf N Farben reduzieren. Die Bildfarben lassen sich als editierbare Palette übernehmen.

    Dazu: Hintergrund entfernen, glätten, Outline ziehen.

  • Ebene

    Ein zweiter Sprite lässt sich halbdurchsichtig unterlegen — zum Abpausen und um Teile von einem Sprite in den anderen zu übertragen.

    Die Zwischenablage überlebt den Sprite-Wechsel.

  • Bild

    Spiegeln, drehen, auf den Inhalt zuschneiden, zentrieren, die Fläche ändern und hart skalieren — Nearest Neighbor, Pixel bleiben Pixel.

    Gibt es eine Auswahl, trifft die Aktion nur sie.

Palettensystem

Farbe ist ein Index

Eine Palette ist ein Mapping von Zahl auf Hex-Farbe. Das Grid speichert nur die Zahlen — deshalb lässt sich ein fertiger Sprite umfärben, ohne ein Pixel anzufassen.

  1. 0transparent
  2. 1#6ed49a
  3. 2#6ec9b3
  4. 3#6ebecc
  5. 4#6eb3e5
  6. 5#2b2b33
  7. 6#6ea8fe
  8. 7#e6e6ea
  9. 8#9a9aa6
  10. 9#33333c

Beispielbelegung. Üblich, aber kein Zwang: 1–4 als Tonleiter hell nach dunkel, 5 als Kontur, 6–9 für Akzente. Jeder Sprite merkt sich seine eigene Palette.

Als Bild

PNG, transparent PDF Spritesheet + JSON-Atlas

Das Spritesheet packt alle Sprites in gleich große Zellen; der Atlas nennt Name, Palette und die echte Lage jedes Frames.

Und zurück

TypeScript JavaScript JSON

Diese drei kommen verlustfrei wieder herein. Der Import wertet keinen Code aus, er liest den Text gegen eine Zeichen-Whitelist.

So arbeitest du

Vom Foto zum Sprite

  1. 1

    Vorlage legen

    Foto laden, mit Shift und Ziehen positionieren, auf eine Handvoll Farben reduzieren. Aus den Bildfarben wird auf Wunsch direkt die Palette.

  2. 2

    Abpausen und säubern

    Mit Stift und Füllen die Flächen setzen, mit Auswahl und Lasso Teile verschieben oder drehen. Undo greift pro Strich, Auto-Save läuft nebenher.

  3. 3

    Mitnehmen

    Format wählen, Datei speichern oder den Code kopieren. Für Backups schreibt Projekt sichern Sprites, Paletten und Layout in eine JSON-Datei.
