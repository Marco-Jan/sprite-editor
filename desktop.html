Installieren

In einer Minute startklar.

  1. ZIP laden und entpacken — Rechtsklick → „Alle extrahieren …“. Den Ordner z. B. auf den Desktop oder nach „Dokumente“ legen, nicht nach „Programme“: sonst kann sich die App nicht selbst aktualisieren.
  2. spritebit.exe doppelklicken — eine Installation braucht es nicht.
  3. Windows warnt beim ersten Start („Der Computer wurde durch Windows geschützt“), weil die App noch nicht signiert ist. Auf „Weitere Informationen“ und dann „Trotzdem ausführen“ klicken — das ist nur einmal nötig. Der Quellcode liegt offen auf GitHub.
  4. Updates meldet die App selbst: „Jetzt aktualisieren“ lädt, prüft und tauscht sie mit einem Klick aus.

Warum Windows warnt

„Der Computer wurde durch Windows geschützt“

Windows warnt bei Programmen, die (noch) kein gekauftes Signatur-Zertifikat haben. spritebit ist Open Source — der Quellcode liegt offen auf GitHub. Klick auf „Weitere Informationen“ und dann „Trotzdem ausführen“; das ist nur einmal nötig.
